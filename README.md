# AMAZON CLONE 




<p>Amazon Clone (HTML & CSS) is a static front-end project that mimics the design of Amazon's homepage using only HTML and CSS. It features a responsive layout, navigation bar, product grid, banners, and footer — all styled to resemble the original site. This project focuses on mastering layout techniques, Flexbox, and responsive design without any JavaScript functionality.</p>
